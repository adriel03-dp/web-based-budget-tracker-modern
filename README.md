# budget-tracker
Modern Budget Tracker
A modern, single-page application (SPA) for tracking your income and expenses, generating reports, and managing your budget—all in your browser with no backend required.
Features
User Authentication: Register, login, and reset password (all data stored locally).
Dashboard: Visual summary with cards and a bar chart (Chart.js).
Add Transactions: Support for income/expense, categories, tags, and per-transaction currency.
Transaction History: View, filter, and manage all your transactions.
Reports: Generate PDF reports (income, expense, combined) with date range filtering.
Profile Management: Edit username and password.
Dark Mode: Toggle between light and dark themes.
Modern UI: Responsive, clean, and visually appealing design.
LocalStorage: All data is stored in your browser—no server required.
Getting Started
1. Clone or Download
Apply to app.js
Run
Or simply download and unzip the project folder.
2. Open in Browser
Just open index.html in your favorite web browser.
No build steps or server required!
Usage
Register a new account or log in.
Add transactions (income or expense) with details, category, tags, and currency.
View dashboard for a summary and bar chart of your finances.
Check transaction history and filter as needed.
Generate PDF reports from the Reports section.
Edit your profile or toggle dark mode from the navigation bar.
Technologies Used
HTML, CSS, JavaScript
Chart.js (for charts)
jsPDF & jsPDF-AutoTable (for PDF reports)
LocalStorage (for all data)
Customization
You can change the default currency, categories, or UI styles by editing the relevant sections in app.js and styles.css.
